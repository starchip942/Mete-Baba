# MB-120 Toros — turbofan ön tasarımı ve simülatörü

- `index.html` — etkileşimli simülatör (tarayıcıda açın; `model.js` ile aynı klasörde olmalı)
- `motor3d.js` — üç boyutlu motor görünümü (three.js)
- `model.js` — gaz modeli, tasarım noktası çevrimi, tasarım dışı eşleşme, geçici rejim
- `test.js` — doğrulama testleri: `node test.js`
- `rapor.js` — `TASARIM_RAPORU.md` dosyasını modelden üretir: `node rapor.js`
- `TASARIM_RAPORU.md` — tasarım raporu (yöntem ve sınırlar dahil)

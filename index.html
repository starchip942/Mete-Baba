Google Haritalar katmanı

Simülasyonu gerçek Google uydu görüntüsü, sokak haritası ve canlı Google trafik verisi üzerine oturtmak için bir Google Maps JavaScript API anahtarı gir. Anahtar yalnızca bu tarayıcıda saklanır.

Anahtar: Google Cloud Console → APIs & Services → Credentials → “Maps JavaScript API”.
